# 授業の意義
文部科学省の提示する「問題解決のためのプログラミング能力」を、私は「与えられた問題に対して適切なアプローチができる能力」と解釈した。プログラミングにおいて、この能力はプログラミングの知識やコーディング力とは必ずしも比例しない。  
私は、検索力[^1]や、問題を解く能力こそが授業で鍛えるべき能力だと考えた。  
さらに、社会に出た時、一人で問題を見つけて一人で解決することは少なく、他者と協力することが多い。そのため、この discussion-based learning を用いた授業は、他者と協力して問題解決をする能力を育成するのに非常に有効であると考える。実際、過去の研究からも discussion-based learning が有効であることは示されている。さらに「検索力」の伸びに着目し、学習者が効率よく検索を行い、自分に必要な情報を得られることを期待する。

[^1]: 検索力とは、検索エンジンを用いて自分の知りたい情報を獲得することができる力を指すことにする。

# 新規性
- ディスカッションの内容を誘導する。-> 検索力の向上
- 検索を積極的に行わせる。

# 授業の流れ
1. クラスを複数グループに分割する
2. それぞれのグループに、サンプルコードとブラウザ、コンパイラ、ヒントを与える
3. 先生は全員に対して問題を与え、生徒は制限時間の中で問題に解答する  
  3.1 この時、生徒は何も知識がないので、web検索を用いて問題に解答する  
  3.2 検索時に利用した検索ワード(検索窓に入力した単語群)を記録しておき、どのような検索ワードが最適であるか考える  
5. いくつかのグループが全員の前で自分たちの思考プロセスを発表する
6. 教師は、事前に用意した(理論上解答といえるであろう)コードを生徒に提示する
