# 1. テーマ
プログラミング能力がインターネット検索能力に与える影響

# 2. インターネット検索能力
具体的にインターネット検索能力を次のように定義する. 
- 必要とする情報を短時間で得る能力
- 情報の真偽を見分ける能力
- 得た情報を問題解決のために活用する能力 

# 3. 背景・提案
- 昨今の情報化社会において, インターネットを用いた検索は日常的に行われている.
  - 検索に係る時間と作業効率は比例する.
  - 現代社会では, 検索によって得た情報を正確に利用することが求められているのも事実である.
- 文部科学省の提示する「問題解決のためのプログラミング能力」[^1]を, 私は「与えられた問題に対して適切なアプローチができる能力」と解釈した. この能力はプログラミングの知識やコーディング力とは必ずしも比例せず, インターネット検索能力こそが養うべき能力だと考えた. 過去の研究により, 協調学習がプログラミング教育において有効であると示されているが, これはインターネット検索能力の向上にも同じだと推測できる. 生徒同士が, 検索によって得た情報について議論をすることにより, 正しく正確な情報を入手する力を養える.う
  - 本研究ではその導入として, プログラミング能力やその経験が, 検索能力に対してどのような影響を与えるのかについて調査を行い, 検索能力を構成するいくつかのパラメータを考案したいと考えている.
- 2023 年になり, OpenAI 社の開発した ChatGPT が非常に注目を集めている. Google などの検索エンジンを用いなくとも, 手軽にまとまった情報を得ることができるシステムに, ユーザは魅力を感じている. しかし, ChatGPT のみを用いた検索は効率が著しく悪く, 実用的とは言えないことは, 経験的にわかっている. 本研究では, 検索エンジンを利用した検索と ChatGPT を利用した検索を実施し, それらのスコアの差について考察する.

# 4. 実験
インターネット検索能力は, コンピュータの使用時間が多ければ多いほど向上することが明らかにされている[^2]が, プログラミング学習によってさらに高水準の能力を獲得できると考える. 具体的には, 4.1 のような能力が得られると考える.

## 4.3 ChatGPT と検索

#### 4.3.1 実験
ChatGPT の出力する回答は, 特に固有名詞を含んだ検索について精度が低いことが認められる. 質問に全く関係のない言葉や, 独自に作り上げた単語を回答する傾向にある. 検索能力の低いユーザは, これらの情報が正確であると誤認し, 利用してしまう.
