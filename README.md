# 1. テーマ
プログラミング教育における協調学習はインターネット検索能力の向上に有効か？

# 2. インターネット検索能力
具体的にインターネット検索能力を次のように定義する. 
- 必要とする情報を短時間で得る能力
- 情報の真偽を見分ける能力
- 得た情報を問題解決のために活用する能力

# 3. 背景・提案
- 昨今の情報化社会において, インターネットを用いた検索は日常的に行われている.
  - 検索に係る時間と作業効率は比例する.
  - 現代社会では, 検索によって得た情報を正確に利用することが求められているのも事実である.
- 文部科学省の提示する「問題解決のためのプログラミング能力」[^1]を, 私は「与えられた問題に対して適切なアプローチができる能力」と解釈した. この能力はプログラミングの知識やコーディング力とは必ずしも比例せず, インターネット検索能力こそが養うべき能力だと考えた. 過去の研究により, 協調学習がプログラミング教育において有効であると示されているが, これはインターネット検索能力の向上にも同じだと推測できる. 生徒同士が, 検索によって得た情報について議論をすることにより, 正しく正確な情報を入手する力を養える.

# 4. 実験
インターネット検索能力はプログラミング学習によって習得できると考える. 
この仮説を示すため, 次のような実験を行う.

## 4.1 検索能力テスト
インターネット検索能力を測るための検索能力テスト(以下, テスト)を実施する.[^2] 
授業前と後に行い, その点数の推移を調べる. 

## 4.2 授業
生徒を2つのグループ(A, B)に分け, それぞれのグループに以下の授業を実施する.

#### ・グループ A
従来の授業方法(講義型)を実施する.

#### ・グループ B
協調学習を実施する.

# 5. 評価
授業方法によるテストの点数の差を統計的に評価する.
