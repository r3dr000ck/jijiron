# テーマ
プログラミング学習は「検索力」の向上に有効か？

# 「検索力」
web 検索によって得た情報を問題解決に活用する能力

# 背景
- 昨今の情報化社会において, インターネットを用いた検索は日常的に行われている.
  - インターネット

# 提案
「検索力」はプログラミング学習によって習得できると考える. 具体的に「検索力」と
- どのような単語を入力することで適切な情報が手に入るのか？
- 情報の真偽をどのように見分けるか？  
- 得た情報を活用できるか？
. この目標達成のためにプログラミング能力は有効か？
